Frontend · 화면 / 플로우 · 네이티브

사용자가 거치는 핵심 화면들을 만들었습니다. 추천을 받는 N스크린, 업로드·추천·상황 보정 화면 전환, 비동기 작업을 기다리는 로딩 상태 UX, 그리고 푸시 알림 세팅까지 — 흐름이 자연스럽게 이어지도록 화면 단을 책임졌습니다.

React Native화면 플로우로딩 상태 UXFirebase FCM 세팅Android
1

기다림을 설명하는 로딩 상태 UX

풀어야 했던 문제추천·이미지 생성은 비동기라 수 초~수십 초가 걸립니다. 빈 화면이면 사용자는 멈춘 줄 알고 이탈합니다.

N스크린(미러) 화면에서 추천 진행을 단계별 상태로 보여줘, 지금 무엇을 하는 중인지 사용자가 알 수 있게 했습니다. '분석 중 → 코디 이미지 생성 중 → 완료'로 이어지는 상태와 마네킹 로딩 연출로 기다림을 설명합니다.

2

업로드 · 추천 · 상황 보정 화면 플로우

풀어야 했던 문제여러 기능이 따로 놀면 사용자는 길을 잃습니다. 화면 사이 전환과 데이터 연결이 매끄러워야 했습니다.

의류 업로드, 추천 메인, 상황 보정 등 핵심 화면을 구현하고 서로 연결했습니다. API 명세에 맞춰 화면을 배선하고, 추천 완료 후 자연스럽게 다음 단계로 이어지도록 전환을 설계했습니다.

3

떨어뜨리는 순간 보기 좋은 카테고리별 스케일

풀어야 했던 문제코디 캔버스에 옷을 놓을 때마다 사용자가 일일이 크기를 맞추면 번거롭습니다.

아우터는 크게, 신발·소품은 작게 — 카테고리마다 어울리는 기본 크기를 정해, 캔버스에 떨어뜨리는 순간 적당한 비율로 배치되게 했습니다.

4

푸시 알림 세팅과 완료 통지 연동

풀어야 했던 문제추천 완료를 사용자가 앱 밖에서도 받으려면, 디바이스 푸시 토큰과 네이티브 알림 설정이 갖춰져야 합니다.

Firebase FCM 설정(infra)을 잡고, 추천 완료 시 알림이 사용자에게 전달되도록 클라이언트 측을 연동했습니다.
