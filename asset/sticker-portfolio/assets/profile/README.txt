STICKER 포트폴리오 — 팀원 프로필 이미지 가이드
==============================================

이 폴더(assets/profile/)에 아래 이름으로 사진을 넣으면
팀 카드와 각 인물 페이지의 아바타가 자동으로 그 사진으로 바뀝니다.
파일이 없으면 지금처럼 이니셜 배지(홍·경·지…)가 그대로 표시됩니다.

[ 넣을 파일 ] — 정확히 이 이름으로
  yoonpyo.jpg     (홍윤표)
  kyungbae.jpg    (김경배)
  jiyoung.jpg     (문지영)
  hyeyeon.jpg     (이혜연)
  jungsik.jpg     (김정식)
  yoonseok.jpg    (장윤석)

[ 권장 규격 ]
  - 정사각형(1:1). 화면에서는 둥근 사각형으로 잘려 보입니다.
  - 크기: 400x400px 이상이면 충분 (팀카드 56px, 인물페이지 78px로 표시).
  - 형식: .jpg 권장. .png도 자동 인식됩니다
    (코드가 .jpg → 없으면 .png 순으로 시도 → 둘 다 없으면 이니셜).
  - 얼굴이 중앙에 오도록 (object-fit: cover로 가운데 기준 크롭됨).

[ 참고 ]
  파일명은 member-<이름>.html 과 동일한 슬러그입니다.
  다른 형식(webp 등)을 쓰고 싶으면 알려주세요. 코드에서 맞춰드릴게요.
