인증 · 회원 (풀스택)

사용자가 서비스에 들어오는 첫 관문을 맡았습니다. 소셜·이메일 로그인, 회원가입/탈퇴 흐름, 그리고 토큰이 만료돼도 끊기지 않는 클라이언트 자동 갱신까지 — 인증·회원 도메인을 프론트와 서버 양쪽에서 구현했습니다.

1

소셜·이메일 로그인 진입

풀어야 했던 문제가입 장벽을 낮추려면 소셜 로그인이 필요하고, 외부 OAuth 토큰을 우리 세션으로 안전하게 교환해야 했습니다.

Google OAuth 서버 연동을 구현하고, 카카오·구글·이메일 로그인 화면과 회원가입 플로우를 만들었습니다. 외부 제공자 인증 후 우리 JWT로 교환해 이후 요청을 인증합니다.

2

토큰이 만료돼도 끊기지 않는 자동 갱신

풀어야 했던 문제액세스 토큰은 짧게 살아야 안전하지만, 만료될 때마다 사용자가 다시 로그인하면 경험이 망가집니다.

클라이언트 HTTP 계층에서 401 응답을 가로채 리프레시 토큰으로 새 토큰을 받아오고, 원래 요청을 자동으로 재시도하게 했습니다. 사용자는 만료를 눈치채지 못합니다. 갱신마저 실패하면 토큰을 비우고 로그인으로 안전하게 되돌립니다.

3

체형 분석 화면

풀어야 했던 문제개인화된 코디 경험을 위해, 사용자의 체형 정보를 입력받는 화면이 필요했습니다.

체형 분석 페이지를 구현해, 프로필과 함께 사용자 맞춤 정보를 다룰 수 있는 기반을 마련했습니다.
