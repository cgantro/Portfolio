통합 관제 백엔드 및 인프라 구축

Description

공항 내 자율 주행 로봇(토잉카)의 고빈도 텔레메트리 데이터를 수집하고 다중 클라이언트에 실시간 동기화하는 관제 시스템 아키텍처 및 백엔드 인프라 전반을 구축했습니다. (기여도: 35%)

  • 메시징 브릿지 (14~28ms 지연): Spring Boot, MQTT, WebSocket을 결합하여 로봇의 상태 데이터를 클라이언트로 실시간 중계. 차량 500대 부하 테스트 환경에서 E2E 지연 시간 평균 0.03초 이내 달성.
  • 경로 추천 (A*): 관제사가 다수의 로봇에게 이동 지시를 내릴 때, 맵 노드 간의 간선을 바탕으로 A* 탐색 알고리즘을 수행하여 최단 경로 시각적 추천 기능 구현.
  • 시계열 DB 최적화: PostgreSQL(TimescaleDB)을 도입, 초 단위로 발생하는 차량 주행 로그(DrivingLog) 데이터의 파티셔닝 및 조회 성능 개선.
  • 네트워크 최적화 (RDP): Ramer-Douglas-Peucker 알고리즘을 서버에 적용하여 주행 경로 데이터를 압축, 대역폭 사용량 80% 절감.
  • 인프라 (CI/CD): GitLab CI/CD와 Docker로 백엔드(Spring Boot) API 서버, 메시지 브로커, DB(Redis)의 자동 배포 환경 구축.

Tech Stack

Java / Spring Boot MQTT & WebSocket PostgreSQL (TimescaleDB) Redis Docker & GitLab CI/CD

고성능 시뮬레이터 엔진 컴포넌트

Description

고가의 JetTank 장비 제약을 극복하고 후배들의 알고리즘 검증 및 웹 기반 학습 데이터 수집을 돕기 위해 제작한 크로스 플랫폼 C++ 시뮬레이터입니다. (기여도: 30%)

  • 스트리밍 병목 해소: 영상 캡처와 네트워크 전송을 분리하는 멀티스레드 기반 Producer-Consumer 패턴을 설계하여 메인 스레드 연산 병목 현상 해소. 30~60fps 수준의 스트리밍 달성 (향후 TCP 한계를 극복하기 위해 UDP/WebRTC 도입 고려 중).
  • 기구학 연산 모듈화: Jetson Nano 규격 및 실제 로봇 내장 코드의 움직임 속도에 맞춰 시뮬레이터 내 로봇의 위치(Odometry) 변화를 계산하는 로직 구현.
  • 크로스 플랫폼 통신: Emscripten(WASM) 기반 WebSocket과 데스크톱 Native(TCP) 통신을 단일 인터페이스로 묶는 추상화된 네트워크 레이어 설계.
  • 제어 UI 구축: Qt 프레임워크를 활용하여 실제 로봇의 모터를 조작하고 센서 상태를 직관적으로 확인할 수 있는 데스크톱 UI 제작.

Tech Stack
