AutowingCar: 통합 관제 시스템 개발

자율 주행 로봇의 실시간 관제 및 제어를 위한 백엔드 및 인프라 구축

Repository 2025.01 – 2025.02

프로젝트 개요: 공항 내 자율 주행 로봇(토잉카)의 고빈도 텔레메트리 데이터를 수집하고 다중 클라이언트에 실시간 동기화하는 관제 시스템 아키텍처 및 백엔드 인프라 전반 구축.

💡 주요 담당 역할 및 성과 (기여도: 35%)

  • 메시징 브릿지 아키텍처 설계: Spring Boot, MQTT, WebSocket을 결합하여 로봇의 상태 데이터를 클라이언트로 실시간 중계하는 파이프라인 구축. k6 부하 테스트 결과, 차량 500대 동시 접속 환경에서도 E2E 지연 시간 평균 14ms ~ 28ms (0.03초 이내) 달성.
  • 경로 추천 알고리즘 설계: 관제사가 다수의 로봇에게 이동 지시를 내릴 때, 맵 노드 간의 간선을 바탕으로 A* 탐색 알고리즘을 수행하여 최단 경로를 시각적으로 추천하는 기능 구현.
  • 시계열 데이터 최적화: PostgreSQL(TimescaleDB)을 도입하여, 초 단위로 발생하는 대량의 차량 주행 로그(DrivingLog) 데이터를 효율적으로 파티셔닝하고 조회 성능을 최적화.
  • 네트워크 최적화: RDP(Ramer-Douglas-Peucker) 알고리즘을 적용, 주행 경로 데이터 포인트를 압축하여 대역폭 사용량 80% 절감.
  • 자동화 배포 환경: GitLab CI/CD와 Docker를 도입하여 백엔드(Spring Boot) API 서버 및 메시지 브로커, DB(Redis) 등 인프라의 자동 배포 환경 구축.

RobotPal: 로봇 시뮬레이터 엔진 컴포넌트

이기종 환경 지원을 위한 스트리밍 및 네트워크 파이프라인 구현

Repository 2025.11 – 2025.12

프로젝트 시작 배경: 고가의 실물 JetTank 장비 사용 기간의 한계를 극복하고, 3D 모델링 지식 없이도 후배들이 로봇 제어 알고리즘 검증 및 웹 기반의 간단한 카메라 학습 데이터를 쉽게 수집할 수 있도록 자체 제작.

💡 주요 담당 역할 및 성과 (기여도: 30%)

  • 스트리밍 성능 개선: 영상 캡처와 네트워크 전송을 분리하는 멀티스레드 기반 Producer-Consumer 패턴을 설계하여 시뮬레이터 메인 스레드의 연산 병목 현상 해소. 30~60fps 수준의 스트리밍을 달성했으나, TCP 환경의 한계가 존재하여 향후 UDP/WebRTC 도입 필요성 도출.
  • 기구학 연산 모듈화: 대상 하드웨어인 Jetson Nano의 규격과 내장 코드의 움직임 속도에 맞춰, 시뮬레이터 내 로봇의 위치(Odometry) 변화를 추적하는 위치 계산 로직 구현 및 ECS 적용.
  • 플랫폼 독립적 통신 레이어: Emscripten(WASM) 기반의 WebSocket과 데스크톱 Native 환경의 TCP 통신을 단일 인터페이스로 추상화한 네트워크 엔진 계층 설계.
  • 제어 UI 구축: Qt 프레임워크를 활용하여 시뮬레이터 파라미터 튜닝뿐만 아니라, 실제 로봇의 모터를 조작하고 센서 상태를 확인할 수 있는 직관적인 데스크톱 UI 개발.
