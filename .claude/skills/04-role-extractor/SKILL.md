# 04 · Role Extractor

## 역할

팀 프로젝트에서 "내가 실제로 한 것"을 분리한다.
팀 전체 기여와 개인 기여를 혼동하면 포트폴리오가 거짓이 된다.

## Input

- 01의 내 커밋 목록 (--author 필터)
- 02의 PROJECT_BRIEF (팀 구조, 서비스 레이어)
- 브랜치 이름에서 내 이름이 포함된 것

## Process

```
1. 내 커밋을 서비스 레이어별로 분류
   예: backend N개, infra N개, frontend N개
2. 커밋 메시지 패턴으로 역할 유형 분류
   - Feat: 기능 구현자
   - Chore/infra: 인프라 담당
   - Fix: 버그 수정 비중
   - Refactor: 구조 개선 비중
3. 가장 많은 커밋 영역 = 주 역할
4. 팀원 커밋과 겹치는 영역 식별 → "(공동)" 표시
5. 내 커밋에만 있는 영역 = 단독 담당
```

## Output → 09-portfolio-writer

```
ROLE:
- 주 역할: (레이어 + 유형)
- 단독 담당 영역: [...]
- 공동 담당 영역: [...] (공동)
- 근거 커밋: (해시 + 메시지 목록)
- 담당하지 않은 것: [...] (팀원 기여)
```

## 금지

- 팀원 커밋을 내 것으로 포함 금지
- 추정 시 "(추정)" 필수
- "전반적인 개발에 참여" 같은 모호한 표현 금지
