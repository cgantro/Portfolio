# 모드 A 최종 검수

요청한 산출물에 해당하는 항목만 확인한다. 작성·반복·저장 기준은 `../SKILL.md`를 따른다.
해당 없는 항목은 실패로 처리하지 않으며, 미확인을 통과로 보고하지 않는다.

## 공고와 근거

- [ ] 필수 조건, 우대사항과 주요 업무를 구분하고 복합 조건의 의미를 보존했는가
- [ ] 회사·직무·기술명과 제출 제약을 원문에 대조했는가
- [ ] 문화·가치관 키워드는 실제 확인된 범위만 추출했는가
- [ ] 충족 요건은 근거로 드러나고, 부분 충족·미충족·미확인은 구분해 보고했는가
- [ ] 역할·기간·수치를 원본이나 사용자 확인과 연결하고 충돌한 사실을 임의로 합치지 않았는가

## 이력서

- [ ] 관련 경험을 우선 배치하고 확인된 수치·기술·역할을 유지했는가
- [ ] 실제로 보존하거나 검증한 범위만 형식·양식 유지로 보고했는가

## 자기소개서

- [ ] 문항의 하위 질문에 모두 답하고 첫 문장이 핵심 답을 전달하는가
- [ ] 질문과 분량에 맞는 경험·구조를 선택하고 불필요한 공통 마무리를 줄였는가
- [ ] 본인의 수행·판단 범위와 팀 성과를 구분했는가
- [ ] 강화한 표현이 확인된 사실과 책임·숙련도 범위를 벗어나지 않는가
- [ ] 비유를 사용했다면 첫 문장부터 답을 전달하고 실제 경험으로 증명되는가
- [ ] SKILL.md의 반복 점검을 수행하고 단어·구절·내용 중복을 교정했는가
- [ ] 동의어 치환으로 반복을 숨기거나 기술 의미를 바꾸지 않았는가
- [ ] 교정 후 의미·필수 기술명·사실성과 원문의 어조를 다시 확인했는가
- [ ] 최종 문안의 분량을 실제 계산하고 계산 기준·미검증 범위를 기록했는가
- [ ] 다른 회사명이나 재사용 문구가 남지 않았는가

## 포트폴리오와 저장

- [ ] 프로젝트 우선순위와 기술적 판단·성과가 공고와 연결되는가
- [ ] 원본·이전 산출물을 보존하고 요청한 결과를 새 버전으로 저장했는가
- [ ] 제출 본문과 근거·확인 질문·검토 메모를 분리했는가
- [ ] 미확인 사실이 필요한 결과는 초안으로 표시하고 최종본으로 보고하지 않았는가
- [ ] 변경 파일, 핵심 변경 내용과 남은 미확인·미검증 사항을 보고했는가
