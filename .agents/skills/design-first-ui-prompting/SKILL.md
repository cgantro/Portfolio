# Portfolio UI brief before changes

Before editing, record:

1. The reader and the decision or question the page must support.
2. The canonical data and evidence the page can show.
3. The information order and the primary action.
4. Responsive behavior at 375px, 768px, and 1440px.
5. Loading, empty, error, keyboard, reduced-motion, and no-JavaScript states that apply.
6. A concrete way to verify the result in a browser.

Use this brief to make code changes. Keep the implementation aligned with `apps/web/DESIGN.md`; do not introduce an unrelated visual system.
