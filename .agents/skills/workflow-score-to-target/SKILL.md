# Portfolio review findings

- Write each finding as route + viewport/state + evidence + user impact + concrete target.
- Fix broken functionality and accessibility first, then responsive layout, then visual polish.
- Do not assign arbitrary numeric scores. A target must be observable, such as “no horizontal overflow at 375px” or “button has a visible focus ring.”
- Re-run the same browser check after the change and retain before/after evidence.
- Report unresolved findings as unresolved.
