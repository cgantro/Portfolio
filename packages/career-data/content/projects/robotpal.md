# RobotPal

## 개요

JETANK 이동 로봇의 주행을 가상 환경에서 재현하고 카메라 영상을 Python 인공지능 모듈로 보내는 C++ 시뮬레이터입니다. 인공지능 명령으로 이동 로봇과 로봇 팔, 집게, 카메라 기울기를 제어합니다.

## 설계 선택

로봇 입력 처리와 주행 계산을 분리해 외부 제어 명령이 시뮬레이션 갱신을 막지 않도록 구성했습니다. 좌우 모터 입력과 실제 주행값을 대조해 가상 로봇의 직진·회전 속도도 보정했습니다.

화면 프레임은 JPEG로 압축해 전송 작업자 네 개에 넘깁니다. 송신이 밀려 오래된 화면이 쌓이지 않도록 대기열은 여섯 프레임으로 제한하고, 가득 차면 가장 오래 기다린 프레임을 버립니다.

## 구현

Qt 화면에서는 실물 JETANK의 상태를 확인하고 조작 입력을 보냅니다. 가상 카메라 프레임은 Python 인공지능 모듈로 전달하고, 응답 명령은 이동·팔·집게 제어에 연결했습니다.

## 문제 해결 과정

카메라 스트리밍을 켜면 화면 갱신률이 낮아졌습니다. 픽셀 버퍼 객체(PBO)를 적용해도 개선되지 않아 Tracy로 화면 복사와 JPEG 압축 구간을 나눠 살폈습니다. JPEG 압축이 주 실행 흐름을 붙잡고 있어 압축과 송신을 작업자 스레드로 옮겼습니다.

이 변경은 프레임 하나의 압축 시간을 단축한 것이 아니라 시뮬레이션이 압축 완료를 기다리는 시간을 줄였습니다. 스트리밍 중 시뮬레이션 갱신률과 카메라 송신률은 함께 높아졌지만, 카메라 송신률은 목표 60 FPS에 못 미쳤습니다. 측정값은 아래 결과에서 각각 확인할 수 있습니다.
