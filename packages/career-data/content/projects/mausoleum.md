# 영묘 (Mausoleum)

## 프로젝트 개요

언리얼 엔진 5로 만든 6인 팀 협동 게임입니다. 플레이어가 방을 만들고 함께 던전을 진행하며, 로비와 게임 안에서 상황에 맞는 실시간 음성 대화를 할 수 있도록 개발했습니다. 개발 기간은 2026년 2~3월이며 C++·UE5·UDP·Opus를 사용했습니다.

## 주요 기능

- 방을 만들거나 기존 방에 들어가 다른 플레이어와 게임을 진행합니다.
- 로비에서는 같은 방 참가자에게 음성을 전달합니다.
- 게임에서는 플레이어 사이의 거리에 따라 음성을 전달합니다.
- 화자별 음성을 복원해 재생하고, 공간 음향으로 게임 내 위치를 반영합니다.
- 게임 진행 서버와 연동해 페이즈별 아이템 생성과 게임 진행을 처리합니다.

## 역할

6인 팀에서 UE5 음성 클라이언트와 C++ UDP 음성 서버를 구현했습니다. 마이크 입력을 화자별 Opus 인코더로 압축해 보내고, 수신 음성을 화자별 디코더로 복원해 재생했습니다. 서버에서는 패킷·세션 확인, 룸 코드별 작업 큐 분배와 음성 중계를 맡았으며 Windows와 Linux의 네트워크 이벤트 처리를 나눠 구현했습니다.

## 트러블슈팅

### 게임 창에 돌아오면 이전 음성이 늦게 재생됨

게임 창이 비활성화된 동안에도 마이크 캡처와 인코딩 데이터가 버퍼에 남아, 포커스를 되찾은 뒤 오래된 음성이 전송됐습니다. 비활성화될 때 캡처 버퍼를 비우고 Opus 인코더 상태를 초기화하도록 바꿨습니다. 다시 활성화된 뒤에는 이전 입력을 이어 보내지 않고 새로 들어온 음성부터 인코딩합니다.

송신 설정은 16kHz 단일 채널, 20ms 프레임, 24kbps입니다. 이 설정은 구성값이며 지연이나 패킷 손실 개선을 측정한 수치는 아닙니다.

## 결과

창을 다시 활성화한 뒤 오래된 입력을 보내지 않도록 바꿔, 포커스 전환 뒤 음성이 정상 재생되도록 수정했습니다.
