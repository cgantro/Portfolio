# 영묘 (Mausoleum)

## 개요

언리얼 엔진 5 협동 게임에 C++ UDP 음성 서버를 연결해 같은 방의 참가자끼리 대화하도록 만든 팀 프로젝트입니다. 로비에서 받은 방 식별 정보를 게임 세션과 음성 서버까지 전달하고, 마이크 입력부터 음성 재생까지 연결했습니다.

## 설계 선택

게임 진행은 언리얼 전용 서버가 맡고 음성은 별도 서버에서 처리합니다. 음성 패킷은 방 식별 코드에 따라 담당 대기열로 보내 같은 방의 입력 순서를 유지하고, 서로 다른 방은 여러 작업 스레드가 나눠 처리하도록 구성했습니다.

## 구현

서버에서 패킷 형식과 세션 권한을 확인한 뒤 방별 대기열로 전달했습니다. 클라이언트에서는 화자별 Opus 인코더와 UDP 송수신, 음성 재생을 연결했습니다.

## 문제 해결 과정

게임 창을 다른 창 뒤로 보냈다가 돌아오면 대기 중이던 음성이 늦게 재생되거나 소리가 깨졌습니다. 오래된 음성을 모두 처리하는 대신 화면 비활성화 시 대기열과 인코더 상태를 초기화해, 복귀 뒤 들어온 음성부터 재생하도록 바꿨습니다.
