# Korean Typography — 한글 타이포 디테일

한글은 영문 대비 시각적 무게가 크고 형태가 정사각형에 가깝습니다. 영문
타이포 룰을 그대로 적용하면 답답하거나 과해 보입니다.

## 1. 폰트 사이즈

영문 룰을 그대로 쓰면 한글이 무거워 보입니다. 한글은 한 단계 작게.

```
영문 본문 11pt  →  한글 본문 10pt
영문 카드 본문 12pt  →  한글 카드 본문 11pt
영문 캡션 9pt  →  한글 캡션 8pt

단, 헤드라인은 동일:
  영문 24pt = 한글 24pt (24pt 한글이 시각적 무게는 충분)

한자 혼용 시:
  영문은 본문과 동일 사이즈
  한자는 +0.5pt (한자는 한글보다 작아 보이는 경향 보정)
```

---

## 2. 자간 (charSpacing)

한글 자간은 미세하게. 양수 자간은 한글에서 부자연스럽다.

```
한글 본문:           0  또는  -0.3  (음수 살짝)
한글 헤드라인 24pt+: -0.5            (응집감)
한글 캡션:           0
한글 대문자 라벨:    사용 금지 (영어 대문자만 적용)

영문 대문자 + 한글 혼용 시:
  영문 부분만 charSpacing 2~3
  한글 부분은 0
```

pptxgenjs에서는 텍스트 배열로 분리해서 각각 charSpacing 다르게 적용 가능.

```javascript
s.addText([
  { text: "KEY METRIC  ·  ", options: { charSpacing: 3, bold: true } },
  { text: "재구매율", options: { charSpacing: 0 } },
], { ... });
```

---

## 3. 행간 (line height)

pptxgenjs는 line spacing 직접 조절이 불편합니다. 폰트 사이즈로 간접 제어.

```
일반 본문: 폰트 사이즈 × 1.45  (한글이 영문보다 더 필요)
  예: 10pt → 14.5pt 행간

헤드라인: 폰트 사이즈 × 1.2
  예: 24pt → 28pt 행간

카드 본문: 폰트 사이즈 × 1.5
  답답함 방지

영문은 1.4~1.45, 한글은 1.45~1.5 권장
```

행간을 명시하려면 `lineSpacing` 또는 `paraSpaceAfter` 옵션 활용.

## 4. 띄어쓰기·구분 기호

한글 데크에서 자주 쓰는 기호 정리.

```
가운뎃점 "·"   →  나열 (권장: 모든 데크에서 콤마 대신)
                   예: "가치·경험·표현"

세로 막대 "|"  →  메타 구분
                   예: "Brandlogy | May 2026"

붙임표 "-"    →  사용 금지 (한글과 충돌, 가운뎃점으로)

콤마 ", "     →  영문 나열에만 (한글 나열은 가운뎃점)
```

### 영문 약어 + 한글 사이 띄어쓰기

```
✅ MZ 세대
✅ AI 시대
✅ KPI 대시보드
✅ PB 콘텐츠
❌ MZ세대 (붙이면 영문이 시각적으로 무거워짐)
```

### 숫자 + 단위 띄어쓰기

```
단위가 한글 1자 (붙임):
  ✅ 1,700만명
  ✅ 250조원
  ✅ 78%
  ✅ 18세

단위가 2자 이상 또는 영문 (띄움):
  ✅ 250 조원 (×) → 250조원 (○)
  ✅ 78 percent → 78%
  ✅ 5 days
  ✅ 12 GB

원칙: 한국어 표준 규칙은 단위 띄움이지만 데크 시각화에서는
숫자 + 단위 1자는 붙여서 한 덩어리로 처리 (페이퍼로지 룰
"거대 그래픽 통합"과 같은 원리).
```

## 5. 줄바꿈

한 줄에 적정 글자 수.

```
한글 본문: 한 줄 25~35자 권장
한글 헤드라인: 한 줄 18~25자 (24pt 기준)
```

### 의미 단위(어절)로 끊기

```
❌ "MZ 소비를 움직이는
    4가지 축"               ← 어절 깨짐, 어색

✅ "MZ 소비를
    움직이는 4가지 축"     ← 어절 단위로 깨짐, 자연스러움

✅ "MZ 소비를 움직이는 / 4가지 축"   ← 슬래시 표기 (수평일 때)
```

### 헤드라인 두 줄 처리

피할 수 없으면 위 줄 길게, 아래 줄 짧게 (역삼각형 안정감).

```
❌  "MZ는
     가격이 아니라 서사에 지갑을 연다"

✅  "MZ는 가격이 아니라 서사에
     지갑을 연다"
```

단, 헤드라인 두 줄은 페이퍼로지 룰 "한 줄 원칙" 위반이므로 자간 -0.5 ~ -1
압축 후에도 두 줄이면 메시지 단순화가 정답.

## 6. 구두점

```
헤드라인 마침표:    사용 X (Action Title은 선언)
본문 마침표:        사용 O
물음표·느낌표:      헤드라인에 사용 가능 (강조 효과)

따옴표:
  ✅ 영문 single  ' '
  ✅ 영문 double  " "
  ❌ 한글 모서리  「」  『』  (점이 너무 부각, 디자인 깨짐)

콜론:
  ✅ "Source: 페이퍼로지 자체조사"  (한글 + 콜론 + 띄움 + 한글)
  ❌ "Source:페이퍼로지"  (붙이면 시각적 충돌)
```

## 7. 한글 폰트 — Pretendard 9 weights

페이퍼로지 데크 표준은 Pretendard.

```
Thin       (100)  →  사용 안 함
ExtraLight (200)  →  사용 안 함
Light      (300)  →  사용 안 함
Regular    (400)  →  본문 일반
Medium     (500)  →  본문 강조, 서브타이틀
SemiBold   (600)  →  드물게 (Bold 대안)
Bold       (700)  →  헤드라인, KPI big number
ExtraBold  (800)  →  드물게 (특별 강조)
Black      (900)  →  사용 안 함 (너무 무거움)
```

pptxgenjs에서 weight는 `bold: true`로 Bold 호출. Medium은
`fontFace: "Pretendard Medium"`로 명시.

```javascript
s.addText("일반 본문", {
  fontFace: "Pretendard",
  fontSize: 10,
});

s.addText("Medium 강조", {
  fontFace: "Pretendard Medium",
  fontSize: 10,
});

s.addText("Bold 헤드라인", {
  fontFace: "Pretendard",
  fontSize: 24,
  bold: true,
});
```

**주의**: Pretendard가 시스템에 설치돼 있어야 합니다. 미설치 시 fallback
폰트로 빌드돼 시각이 완전히 달라짐. `fc-list | grep Pretendard`로 확인.

## 8. 폰트 임베드 (호환성)

데크를 다른 PC로 옮길 때 폰트가 깨지지 않게 임베드 필요.

```javascript
// pptxgenjs 자체에 폰트 임베드 옵션은 없음
// PowerPoint에서 수동 적용 필요:
//   파일 → 옵션 → 저장 → 파일에 글꼴 포함
//
// 또는 빌드 후 LibreOffice로 임베드:
//   soffice --headless --convert-to pptx:"Impress MS PowerPoint 2007 XML" deck.pptx
```

## 9. 자주 하는 실수

1. **한글에 양수 charSpacing** — 어색하다. 0 또는 -0.3으로
2. **한자에 한글과 동일 사이즈** — 한자가 작아 보임, +0.5pt 권장
3. **헤드라인에 마침표** — Action Title은 선언, 마침표 X
4. **이탤릭 한글** — 절대 금지 (한글 이탤릭은 시각적 결함)
5. **한글 따옴표 「」 사용** — 점이 부각돼 디자인 깨짐, 영문 ' ' " " 사용
6. **숫자 + 한글 단위 띄움** — "250 조원" 어색, "250조원"
7. **MZ세대 처럼 영문 + 한글 붙이기** — 띄어쓰기 "MZ 세대"
8. **모든 텍스트에 같은 폰트 weight** — 위계 없음, Regular/Medium/Bold 위계 분명히
9. **Pretendard 미설치 환경에서 빌드** — 시스템 폰트로 fallback, 시각 완전 다름
10. **본문에 폰트 사이즈 14pt 미만 + 라이트 컬러** — 가독성 0
