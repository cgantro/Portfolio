# Grid System — 12 컬럼 그리드 표준

모든 카드·박스·차트는 12 컬럼 그리드 단위로 정렬돼야 시각적 리듬이
생깁니다. 이 파일은 좌표 계산의 수학적 기준.

## 1. 기본 계산

```
슬라이드 폭:    13.333"
좌우 마진:      각 0.422"  →  가용 폭 12.489"
컬럼 수:        12
컬럼 간 gap:    0.10"

컬럼 폭 = (12.489 - 11 × 0.10) / 12 = 0.949"
```

---

## 2. 컬럼 묶음 폭 (gap 포함)

```

 3 컬럼:  3.046   ← 4-up 카드 = 3컬럼씩

10 컬럼: 10.389
11 컬럼: 11.438
12 컬럼: 12.489   (전체 가용 폭)
```

## 3. 표준 카드 묶음 좌표

### 4-up 카드 (3컬럼씩 × 4)
```
카드 폭: w=3.046, 카드 간 gap=0.10
x 좌표: x[i] = 0.422 + i × 3.146   (i = 0, 1, 2, 3)

i=0:  x=0.422
i=1:  x=3.568
i=2:  x=6.714
i=3:  x=9.860
```

### 3-up 카드 (4컬럼씩 × 3)
```
카드 폭: w=4.095, 카드 간 gap=0.10
x 좌표: x[i] = 0.422 + i × 4.195   (i = 0, 1, 2)

i=0:  x=0.422
i=1:  x=4.617
i=2:  x=8.812
```

### 2-up 카드 (6컬럼씩 × 2)
```
카드 폭: w=6.193, 카드 간 gap=0.10
x 좌표: x[i] = 0.422 + i × 6.293   (i = 0, 1)

i=0:  x=0.422
i=1:  x=6.715
```

`build-helpers.js`의 `GRID` 객체가 이 계산을 함수화합니다.

```javascript
const H = require("./scripts/build-helpers");

// 4-up
[0,1,2,3].forEach((i) => {
  const { x, w } = H.GRID.fourUp(i);
  H.card(s, pres, { x, y: 2.40, w, h: 1.55 });
});
```

## 4. 비대칭 분할 (12 컬럼 비율)

비대칭은 의도된 비율을 따라야 합니다. 자의적이면 안 됨.

```
4:8 = 33% : 67%   (4 컬럼 + 8 컬럼)
5:7 = 42% : 58%   (5 컬럼 + 7 컬럼)  ← 황금비 근접, 가장 자주
3:9 = 25% : 75%   (3 컬럼 + 9 컬럼)
2:10 = 17% : 83%  (2 컬럼 + 10 컬럼)
```

5:7이 가장 안정적. 좌측 KEY MESSAGE + 우측 차트 조합에 최적.

`box-system.md`의 7가지 패턴이 12 컬럼과 정확히 맞아떨어집니다.

## 6. 광학적 정렬 (Optical Alignment)

수학적 정렬과 시각적 정렬은 다릅니다. 다음은 의도적 어긋남.

### 큰 도형 옆 작은 도형
큰 도형이 시각적으로 더 커 보이므로, 작은 도형은 약간 들여써야 같아 보임.
```
조정: 작은 도형 x 좌표를 0.02~0.05" 안쪽으로
```

### 둥근 도형 vs 사각 도형
둥근 도형은 모서리가 잘려 보여 시각적으로 작아 보임.
```
조정: 둥근 도형을 약간 더 큼직하게 (w/h 0.05" 추가)
```

### 텍스트가 도형 우측에 있을 때
텍스트 좌측 padding을 더 크게 잡아야 광학적 균형.
```
조정: 좌측 padding 0.18" 권장 (일반 0.15"보다 큼)
```

### 중앙 정렬된 텍스트의 시각적 중앙
대문자만의 텍스트는 위쪽이 무거워 보임. valign middle 위치를 약간 아래로.
```
조정: 텍스트 y 좌표 +0.02"
```

## 7. 빈번한 정렬 오류

다음 패턴은 즉시 슬롭으로 분류됩니다.

### 오류 1: 카드 폭이 컬럼과 안 맞음
```
❌ 4-up 카드를 w=3.0으로 설정 → 12.489에서 0.046 부족
✅ w=3.046 정확히
```

### 오류 2: gap이 0.08 / 0.12 같은 비표준 값
```
❌ gap=0.08 또는 0.12
✅ gap=0.10 (4-up·3-up·2-up), gap=0.20 (Box 가로), gap=0.15 (Box 세로)
```

### 오류 3: 마진이 0.422가 아닌 값
```
❌ 슬라이드 좌우 마진 0.5 또는 0.4
✅ 정확히 0.422 (Box System 부모 영역과 일치)
```

### 오류 4: 카드 height가 들쑥날쑥
```
❌ 4-up 카드 4개가 각각 1.50 / 1.55 / 1.52 / 1.55
✅ 모두 1.55 통일
```

### 오류 5: 가운데 정렬 의존
시각적 가운데와 수학적 가운데 다를 때 가운데 정렬은 어긋남.
```
❌ align: "center" 의존
✅ x 좌표 계산해서 좌측 정렬
```

## 8. 빠른 계산 공식

자주 쓰는 좌표 계산을 함수로.

```javascript
// 카드 그리드 좌표 (build-helpers.js GRID 객체)
const GRID = {
  fourUp: (i) => ({ x: 0.422 + i * 3.146, w: 3.046 }),
  threeUp: (i) => ({ x: 0.422 + i * 4.195, w: 4.095 }),
  twoUp: (i) => ({ x: 0.422 + i * 6.293, w: 6.193 }),
};

// 임의 컬럼 묶음 → 좌표
function colSpan(startCol, numCols) {
  const colW = 0.949, gap = 0.10;
  const x = 0.422 + (startCol - 1) * (colW + gap);
  const w = numCols * colW + (numCols - 1) * gap;
  return { x, w };
}

// 사용 예
colSpan(1, 5);   // 1~5컬럼 → { x: 0.422, w: 5.144 }
colSpan(6, 7);   // 6~12컬럼 → { x: 5.668, w: 7.242 }
```

콘텐츠 max y:    6.05 (HARD LIMIT)

Bottom Strip:    y=6.85, h=0.30
