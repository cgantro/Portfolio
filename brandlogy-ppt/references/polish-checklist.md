# Polish Checklist — 미세조정 32항목

극도의 아름다움은 미세조정에서 결정됩니다. `qa-checklist.md`가 "기능적
완성"이라면 이 파일은 "심미적 완성"입니다. 빌드 후 한 번 더 다듬을 때
사용.

## 사용법

JPG 슬라이드를 한 장씩 펼쳐놓고 다음 32항목을 점검. 통과 안 되는
디테일이 보이면 즉시 수정 → 재빌드.

---

## A. 여백·간격 (5항목)

- [ ] 1. 카드 안 padding이 사방 동일 (≥ 0.18")?
- [ ] 2. 카드 간 gap이 한 슬라이드에서 통일된 값?
- [ ] 3. 분할 박스 가로 gap=0.20", 세로 gap=0.15" 표준 준수?
- [ ] 4. 텍스트 박스가 카드 끝에 닿지 않음 (≥ 0.10" 마진)?
- [ ] 5. 슬라이드 가장자리에 ≥ 0.422" 마진?

## B. 라인·테두리 (3항목)

- [ ] 6. line 두께 단계 3개 이내 (0.5/1.0/1.5pt)?
- [ ] 7. 라인 색상 단계 3개 이내 (border/containerLine/brand)?
- [ ] 8. 점선·실선 혼용 시 의미 구분 명확?

## C. 라운드·도형 (3항목)

- [ ] 9. rectRadius 단계 3개 이내 (0.06/0.10/0.14/0.18)?
- [ ] 10. 큰 박스(>4")는 0.18, 작은 박스(<3")는 0.10~0.14?
- [ ] 11. SO WHAT은 rectRadius=0.06 (다른 카드보다 작게 — 조용히 자리)?

## D. 그림자 (3항목)

- [ ] 12. shadow opacity ≤ 0.10 (진한 그림자 금지)?
- [ ] 13. shadow blur는 6 / 12 / 15 중 하나?
- [ ] 14. 강조 카드 1개만 brand glow shadow?

## E. 색상 (4항목)

- [ ] 15. 한 슬라이드 fill 색 ≤ 5종?
- [ ] 16. brand 단일 톤이 메인 (60~70% 영역)?
- [ ] 17. 강조는 brandDeep 또는 brandPale 1곳만?
- [ ] 18. 채도 있는 색 (brand 계열 외) 0개?

## F. 타이포 (4항목)

- [ ] 19. 폰트 굵기 단계 3개 이내 (Bold/Medium/Regular)?
- [ ] 20. 폰트 사이즈 단계 5개 이내?
- [ ] 21. 헤드라인은 항상 동일 위치/크기/굵기 (모든 슬라이드)?
- [ ] 22. 한글 자간 0 또는 -0.3 (양수 금지)?

## G. 정렬 (4항목)

- [ ] 23. 12 컬럼 그리드 단위로 카드 정렬?
- [ ] 24. 카드 안 텍스트 좌측 정렬 (중앙 정렬은 라벨에만)?
- [ ] 25. 모든 텍스트 박스 margin 0?
- [ ] 26. 광학적 정렬 검토 (큰 도형 옆 작은 도형 들여쓰기 0.02~0.05")?

## H. 위계 (3항목)

- [ ] 27. 한 슬라이드 = 1 강조 (강조 카드 1개만)?
- [ ] 28. 강조 시그널이 다중 변수 (색+크기+그림자 조합)?
- [ ] 29. 약 카드는 caption color로 톤다운?

## I. 리듬 (2항목)

- [ ] 30. 같은 종류 요소(카드 4개)가 동일 styling?
- [ ] 31. 변주(강조 1개)가 의도적이며 명확?

## J. 최종 판별 (1항목)

- [ ] 32. **"이 슬라이드 1초 안에 메시지 + 시선 동선이 한 번에 보이는가?"**

이 한 항목이 통과되지 못하면 30항목이 다 통과돼도 다시 작업.

---

## 자주 발견되는 미세 결함 (디버깅 가이드)

빌드 후 가장 자주 잡히는 결함 패턴.

### 결함 1: gap이 0.10/0.15/0.10
세 카드 간 gap이 다른 값. 시각적 리듬 깨짐.
→ 모두 0.10 또는 모두 0.15로 통일.

### 결함 2: shadow opacity 0.15 / 0.20 혼용
카드마다 그림자가 다른 강도. "강조"가 사라짐.
→ 일반 카드는 0.05~0.08, 강조 카드만 brandGlow 0.20.

### 결함 3: rectRadius 0.06 / 0.10 / 0.18 한 슬라이드 혼용
도형마다 라운드가 다 다름. 통일감 깨짐.
→ 큰 박스 = 0.18, 작은 카드 = 0.10, SO WHAT = 0.06 (이 3개만).

### 결함 4: 강조 카드가 2개 이상
4개 카드 중 2개가 brandPale fill. 강조가 사라짐 (One emphasis 위반).
→ 진짜 핵심 1개만 강조, 나머지는 white.

### 결함 5: 카드 끝에 텍스트가 닿음
padding 부족 (특히 우측·하단). 답답한 인상.
→ 텍스트 박스 좌표를 padding 0.20" 차감해서 다시 계산.

### 결함 6: 라벨이 회전됨
세로 막대에 긴 라벨이 들어가 회전됨. 슬롭 신호.
→ 가로 막대로 전환 또는 라벨 단축.

### 결함 7: 헤드라인이 두 줄
24pt 헤드라인이 두 줄로 wrap.
→ 자간 -0.5 → -0.8 → -1.0 순차 적용. 그래도 두 줄이면 메시지 단순화.

### 결함 8: SO WHAT이 너무 김
한 줄에 안 들어가 wrap.
→ "X 아닙니다. Y일 뿐입니다" 패턴으로 단축. 최대 35자.

### 결함 9: 차트 데이터 라벨이 막대와 겹침
dataLabelPosition 잘못 지정 또는 막대 너무 짧음.
→ "outEnd" 명시, 값 축 범위 조정.

### 결함 10: Pretendard가 시스템 폰트로 fallback
빌드 환경에 폰트 미설치 또는 fontFace 오타.
→ `fc-list | grep Pretendard` 확인, `fontFace: "Pretendard"` 정확히.

## Polish 우선순위 (시간 부족 시)

전부 통과시키기 어렵다면 다음 순서:

1. **§J 32번** — 1초 안에 메시지 + 시선 동선 (가장 중요)
2. **§E 색상 4항목** — 컬러 통일성 (가장 눈에 띔)
3. **§A 여백 5항목** — 답답함 제거
4. **§F 타이포 4항목** — 통일성
5. **§H 위계 3항목** — One emphasis
6. 나머지는 작업 가능한 만큼

처음 5개 항목만 통과해도 데크 품질은 80% 이상 올라갑니다.
