# 콘텐츠 검수 메모

이 파일은 내부 검수용이며 사이트에 표시하지 않습니다. 프로젝트 페이지의 문장은 프로젝트 전체 설명, 본인 담당, 구현, 실제 문제 해결, 검증 범위를 분리해 구성합니다.

## 반영 기준

- 한국어 개발자가 직접 설명하는 문장으로 쓰고, 검수 보고서처럼 보이는 표현은 본문에서 제외합니다.
- 측정값에는 기간·조건·대상을 함께 표시하고, 구현 설정값은 성과처럼 다루지 않습니다.
- 실제 문제 해결과 설계 선택을 분리합니다. 근거가 확인되지 않은 코드 예시는 추가하지 않습니다.
- 외부 저장소·공개 문서와 역할, 팀 규모, 기간, 수치, 코드 발췌를 대조합니다.
- 코드 블록은 가독성을 위해 색상을 적용하고, 발췌에는 원문 경로를 연결합니다.
- 큰 시연 영상 파일은 실행 데모를 대신하지 않습니다. GraspLink 페이지는 브라우저용 시뮬레이터를 페이지 안에 표시하고 저장소·새 탭 경로도 제공합니다.

## 반영 상태

- 홈 화면: 직무 소개, 대표 프로젝트, 담당 역할, 기술 영역, 학력·활동, 연락처로 정리했습니다.
- 프로젝트: 페이지마다 필요한 섹션만 보여주고, 사례는 현상·원인·수정·결과 순서의 읽기 흐름으로 정리했습니다.
- GraspLink: 실제 구현과 회귀 테스트가 있는 J6 등가각 문제를 중심 사례로 사용합니다. MovePose와 MoveLinear의 동작 의미를 구분하고 페이지 안에 인터랙티브 웹 시뮬레이터를 표시합니다.
- RobotPal: 공식 프로젝트 기간(2025.11–2025.12)과 후속 벤치마크(2026.10)를 나눴습니다. 구성별 비교와 Tracy 진단값은 별도 표로 보여줍니다.
- 영묘: 룸별 워커 분배는 구현·설계로, 앱 복귀 후 오래된 음성 재생은 실제 문제 해결 사례로 분리했습니다.
- AutoWing Car: MQTT 상태 역행과 커밋 전 이벤트 발행을 실제 문제 해결로 남겼습니다. 경로 탐색은 구현 설명, k6 결과는 검증에 둡니다.
- README: 실제 활성 데이터 경로, 시뮬레이터 URL, GitHub Pages 배포 흐름에 맞춰 갱신했습니다.

## 남은 확인

- 이 세션에서는 브라우저 런타임을 사용할 수 없어 1440px·768px·390px에서 실제 화면, iframe 실행, 클립보드 동작을 직접 확인하지 못했습니다.
- `npm run build`가 통과했고, Vite 미리보기에서 `/Portfolio/`, GraspLink 경로, 22MB 웹 시뮬레이터 경로가 모두 HTTP 200을 반환했습니다.
- 빌드에는 기존 `coi-serviceworker.min.js` 스크립트를 Vite가 번들링하지 않는다는 경고가 있습니다. 브라우저에서 cross-origin isolation과 시뮬레이터 조작은 확인하지 못했습니다.
